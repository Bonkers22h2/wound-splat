## Protocol decision before observing model performance

The original audit conflates uncertain duplicate identity with the constraint
that related images must remain in the same fold. The 40 mixed-grade candidates
are not proven label conflicts (no exact-image cross-grade conflict was found).
For an exploratory run, use an explicit `conservative-splits` grouping policy:

- Keep **all** filename, exact-image and approximate-hash edges as split-group
  constraints; this does not remove a single previous leakage constraint.
- Form sample/metric groups from grade-scoped export source stems and exact
  transformed pixels. Never average different labels together. Exact-image
  conflicting labels still block training.
- Preserve original files and expert-provided labels; do not delete candidates
  or claim to have adjudicated them. Record mixed-grade candidate groups as
  unresolved warnings. Patient independence remains unknown.
- Source groups are export units, not verified independent wounds. Reused
  filenames within a grade may still merge unrelated images. Source-level
  metrics average augmented views and are not single-photo clinical accuracy.

This supersedes the earlier blanket block on all mixed-grade similarity
candidates for this exploratory run only. The default strict audit remains
available. Both policies reject exact-image conflicting labels.

## Execution plan

1. Add regression tests for separate sample vs split groups, mixed-grade
   candidates, exact conflicts, and deterministic split isolation; observe
   failure, implement, and run the combined test suite.
2. Re-audit the unchanged archive into a new directory using the explicit new
   policy. Verify counts, manifest fingerprint and five valid grouped folds.
3. Train the unchanged ImageNet V2 frozen-backbone baseline for 20 epochs on
   each of five folds. Evaluate outer folds only after fitting; do not tune
   hyperparameters using these results.
4. Fit one fresh full-data model for research predictions under the user's
   training instruction. Keep its training-set predictions separate from
   held-out CV examples; no independent score is attached to the full fit.
5. Verify saved checkpoints and complete out-of-fold coverage, record aggregate
   metrics and example held-out predictions in the experiment documentation,
   obtain code review of the grouping change, and commit code/docs. Retain
   raw data, per-image results and checkpoints locally.
